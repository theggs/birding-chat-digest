# 分享长图

完整报告写完后，可以另生成一张适合在手机和群里转发的 PNG 长图。长图是完整报告的**筛选版**；完整报告和数据覆盖不受影响。

## 内容筛选

- 保留：标题、日期、统计区间、分组总结。
- 去掉：“数据覆盖”整节和媒体数量统计。
- 不收录：情绪化争执、人身攻击、对个人动机或品行的评价、退群纠纷、嘲讽指责。
- 筛选以句子和观点为单位：只删除攻击、嘲讽、情绪化表达和对个人的评价，同一话题中可独立理解的中立观点照常保留，可以去掉刺激性措辞、只转述观点本身；只有删完后已不剩可独立理解的内容时，才删去整个话题。不匿名后继续传播攻击性内容，也不暗示被删的事件。
- 正常的观点分歧和经验交流要保留，并如实呈现纠正和未定结论。
- 删减后按展示顺序重新连续编号。

把筛选后的 Markdown 另存为 `report-preview.md`，和完整的 `report.md` 区分开。

## 渲染

用浏览器渲染 GitHub 风格的 Markdown 后截图，不自己绘制海报版式。

| 参数 | 值 |
|---|---|
| 主题 | 白天时段用 GitHub 浅色，晚间时段用 GitHub 暗色（按计划时段选，不按实际运行时间） |
| 视口和内容宽度 | 390 CSS px（不要退回桌面宽度） |
| deviceScaleFactor | 3（导出 1170 px 宽） |
| 正文 | 18px，行距 1.75，段落间距 20px |
| 内边距 | 左右 18px，上下 24px |
| 标题 | h1 27px、h2 24px、h3 22px、h4 20px |
| 字体 | 优先 -apple-system / PingFang SC |

- 鸟名保持加粗；不加装饰页眉、页脚或卡片。
- 只出一张连续长图，不切片、不分页。
- 保存为 `report-preview.png`；同一期重跑时直接覆盖。
- 取数整体失败时不生成长图；渲染失败时如实说明，完整报告照常输出，并删除归档目录中旧的 `report-preview.*`，避免旧长图被当成本期结果。
- 审稿意见和审稿处理说明不进入长图。

常用工具：Playwright / Puppeteer 加载 [github-markdown-css](https://github.com/sindresorhus/github-markdown-css)，`fullPage: true` 截图。

建议把上述渲染参数固化成一个脚本（输入筛选版 Markdown、主题和输出路径），定时任务每次只调用脚本，不让 Agent 每次重新编写渲染代码。这样排版稳定，也不会在归档目录里留下临时的 .js/.html 文件。
